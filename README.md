# 💱 Currency Converter Application

A Java-based desktop application that allows users to convert currencies using live exchange rates. Built with Java Swing, JDBC, and SQLite, the application provides a user-friendly interface with conversion history and historical exchange rate visualization.

## 🚀 Features

- **Live Currency Conversion** – Fetches current exchange rates through API integration.
- **Multiple Currency Support** – Supports USD, EUR, INR, GBP, JPY, AUD, CAD, SGD, CNY, and AED.
- **Currency Swapping** – Quickly swaps source and target currencies.
- **Conversion History** – Automatically saves successful conversions.
- **History Management** – View and clear previous conversion records.
- **Exchange Rate Graph** – Visualizes historical exchange rate trends.
- **Input Validation** – Handles invalid inputs and conversion errors.
- **User-Friendly Interface** – Interactive desktop GUI developed using Java Swing.

## ⚙️ Application Workflow

1. Launch the Currency Converter application.
2. Enter the amount to convert.
3. Select the source currency.
4. Select the target currency.
5. Click the **Convert** button.
6. View the converted amount and exchange rate.
7. Access the conversion history to view previous transactions.
8. View historical exchange rate trends using the graph.

## 🗄️ Database

The application uses SQLite to maintain conversion history.

Stored information includes:
- Source currency
- Target currency
- Entered amount
- Converted amount
- Conversion date and time

## 🌐 API Integration

The application integrates external exchange rate APIs to retrieve live currency rates and historical exchange rate information.

## 🎯 Project Objective

The main objective of this project is to develop an efficient and user-friendly desktop application that simplifies currency conversion using live exchange rates while maintaining conversion history and displaying historical exchange rate trends.
